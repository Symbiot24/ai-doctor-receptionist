# 🏥 AI Doctor Appointment Agent

An AI-powered Telegram assistant that helps patients:

- Book appointments
- Cancel appointments
- Reschedule appointments
- Check appointment status

## Tech Stack

- Python
- Groq
- Telegram Bot API
- Neon PostgreSQL
- SQLAlchemy
- Pydantic
- Loguru

## Architecture

Telegram User
↓
Telegram Bot
↓
AI Agent
↓
Appointment Tools
↓
Neon PostgreSQL
